# Fresh-context review, C7–C9 (hostile)

Scope: spec/spec.yaml, spec/SAP_SIM.md, spec/SAP_SIM_amendment_1.md, analysis/method_eval.py, analysis/acceptance.py, analysis/export_models.py, sama/sama_method.py, sama/conformal.py, sama/streaming.py, results/c7_summary.json, results/tables/{c7_*,c8_*,budget_*,acceptance*,export_parity,abstention_tradeoff}.csv, ISSUES.md (last section). I also grepped two call sites (sim/generate.py:85, :113) to confirm how the features were built. Checks were run read-only on results/cache/c7_test_predictions.csv.gz.

Leakage checks passed: in each fold, the test, train-proper and calibration participants are disjoint (method_eval.py:128-136; each pid has one fold in the cache, with 36 per stratum). The best baseline is chosen on outer-training participants only (:148-151). Reference HR is not an input to `window_features` X/cond/q. The ECG-derived `ppg` is used only as the training target. The HRV `hr_hint` comes from the camera (generate.py:112-113). No inner tuning on test folds was found. The exceptions are listed below (R7-06, R7-07, R7-10).
